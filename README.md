# 🎬 Netflix Data Analysis Using SQL


## 📌 Project Overview

This project explores Netflix's content library using SQL to solve real-world business problems and uncover insights about movies, TV shows, genres, countries, ratings, and content trends.

Using a structured Netflix dataset, I performed data cleaning, schema design, and analytical SQL queries to answer business-driven questions that support content strategy and decision-making.

---

## 🎯 Objectives

- Analyze Netflix's content catalog
- Practice advanced SQL concepts
- Solve business-oriented analytical problems
- Generate actionable insights from entertainment data

---

## 🛠️ Tools & Technologies

- PostgreSQL
- SQL
- CSV Dataset
- Data Modeling

---



## 📊 Analysis Performed

The project covers multiple business questions, including:

✔ Content distribution by type (Movies vs TV Shows)

✔ Most common ratings on Netflix

✔ Top countries producing Netflix content

✔ Year-wise content additions

✔ Genre analysis

✔ Longest movies and TV shows

✔ Content trends over time

✔ Director and cast analysis

✔ Country-wise content distribution

✔ Content growth insights

---

## 🔑 SQL Concepts Used

- Joins
- CTEs (Common Table Expressions)
- Aggregate Functions
- Window Functions
- CASE Statements
- String Functions
- Date Functions
- Subqueries
- Ranking Functions

---

## 📈 Key Insights

- Movies make up the majority of Netflix's catalog.
- The United States contributes the largest share of content.
- Content additions increased significantly after 2015.
- Drama and International genres dominate the platform.
- TV Shows have shown rapid growth in recent years.
